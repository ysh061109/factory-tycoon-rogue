# 기획서 (가제: 이름 미정)

> 상태: 초안. 사용자가 말한 내용은 **[확정]**, Claude가 정리하면서 덧붙인 내용은 **[제안]**, 아직 정해야 할 것은 **[미정]**으로 표시합니다.

## 1. 한 줄 콘셉트

Create로 만든 공장 생산품을 주민에게 납품하고, 공장을 구경하러 온 주민에게 평가받아 돈을 버는 **로그라이크 + 타이쿤 + 시뮬레이션** 애드온. 라운드가 끝날 때마다 카드를 골라 공장과 가게를 성장시킵니다. **[확정]**

## 2. 기술 전제

- Minecraft 1.21.1, NeoForge **[확정]**
- Create 6.0.x 애드온 **[확정]** (1단계는 Create 없이도 동작하게 만들고, 이후 연동 **[제안]**)
- 개발과 빌드는 Claude가 담당하고, 빌드는 GitHub Actions로 jar를 생성 **[확정]**
- 상세 아이디어는 사용자가 계속 추가 **[확정]**

## 3. 핵심 게임 루프

1. 주민이 공장 생산품을 **대량으로 주문**합니다. 예: 철 도구 200개 납품 **[확정]**
2. 플레이어는 Create 공장을 만들고 확장해서 주문을 처리합니다.
3. 주민이 **공장을 직접 보러 와서 평가**하고 돈을 줍니다. **[확정]**
4. 라운드가 끝나면 **카드 3장 중 1장을 선택**해 업그레이드합니다. **[확정]**
5. 평판이 오르면 더 많고 더 부유한 방문객이 찾아옵니다. **[확정: 방문객 증가]**
6. 다음 라운드는 더 큰 주문과 새로운 조건으로 시작합니다. (로그라이크 요소) **[제안]**

## 4. 카드 시스템

사용자가 준 예시:
- 공장 인기 증가로 **방문객 증가** **[확정]**
- **도구 수요 증가** **[확정]**

Claude가 정리한 카드 분류 **[제안]**:

| 분류 | 효과 예시 |
|---|---|
| 방문객 | 방문객 수 증가, 부유한 방문객 출현 확률 증가 |
| 수요 | 특정 품목(도구, 음식 등) 주문량과 단가 증가 |
| 평가 | 평가 점수 보너스, 평판 획득량 증가 |
| 리스크 | 주문량 2배, 보상도 2배 / 제한시간 단축, 보상 증가 |
| 자동화 | 공장 속도 증가, 납품 자동화 보조 |
| 특수 | 특별 손님(유튜버 등) 방문, 일회성 대박 주문 |

- 카드는 데이터 파일(JSON)로 정의해서, 코드를 건드리지 않고 카드를 추가하고 수정할 수 있게 합니다. **[제안]**
- 희귀도(일반, 희귀, 전설)를 두고 라운드가 진행될수록 좋은 카드가 나오게 합니다. **[제안]**

## 5. 손님과 주문

- 주민이 찾아와서 거래합니다. **[확정]**
- 유튜버 같은 특별 손님이 찾아와서 구매하거나 방송하듯 평가합니다. **[확정: 초기 요청]**
- 손님마다 소지금과 취향이 달라서, 오는 손님이 평판에 따라 달라집니다. **[제안]**
- 주문은 라운드마다 자동으로 생성되고, 품목은 플레이어의 공장 규모에 맞춰 조절됩니다. **[제안]**

## 6. 공장 평가

주민이 공장을 보고 평가한다는 아이디어는 구현 난이도가 가장 높습니다. 현실적인 평가 방식 **[제안]**:

- 생산량과 가동률
- 생산 품목의 다양성
- 공장 규모(범위 안의 Create 부품 수)
- 평가 구역을 만들어 주면, 방문객이 그 안을 돌아다니며 구경

공장의 "외관 점수"는 처음에는 넣지 않고, 위의 수치 기반 평가로 시작합니다.

## 7. 개발 단계 **[제안]**

| 단계 | 내용 | 난이도 |
|---|---|---|
| 1단계 | 주문 생성, 아이템 납품, 보상, 카드 선택 UI | 보통 |
| 2단계 | 주민 방문 AI, 거래 화면 | 보통 |
| 3단계 | 공장 평가와 평판, 방문객 변화 | 어려움 |
| 4단계 | Create 연동 강화, 특별 손님, 카드 확장 | 보통 |

현재 진행 상황: 빈 모드 뼈대와 자동 빌드 설정까지 완료.

## 8. 아직 정해야 할 것 **[미정]**

- 모드 이름
- 돈 시스템: 에메랄드, 자체 코인, 또는 Create: Numismatics 연동
- 라운드 길이: 마인크래프트 며칠 단위인지, 실시간 몇 분인지
- 실패 조건: 라운드 목표 미달 시 어떤 불이익이 있는지(게임 오버가 있는지)
- 멀티플레이 지원 여부
- 주문과 납품 방식: 전용 블록에 넣는지, Create 컨베이어로 자동 납품하는지
